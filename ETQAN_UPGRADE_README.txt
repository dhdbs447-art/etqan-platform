تمت إضافة حزمة التطوير:
- مركز متابعة الطلبات.
- حالات الطلب: جديد، جاري التنفيذ، مكتمل، تم التسليم.
- سجل تحديثات لكل طلب.
- إشعارات داخلية وصوتية.
- تصنيف الأعضاء: عميل جديد، عميل دائم، VIP، موقوف.
- إحصائيات مختصرة.
- نسخ احتياطي JSON.
- زر مركز متابعة يظهر للمختص والعضو.
- لم يتم حذف نظام الشات والرسائل العامة الموجود.
