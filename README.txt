# منصة إتقان التعليمية — النسخة الاحترافية الكاملة

## التشغيل
افتح ملف `index.html` مباشرة، أو ارفع الملفات على GitHub Pages / Netlify / Firebase Hosting.

## الدخول للوحة الإدارة
اسم المستخدم: admin
كلمة المرور: admin

يمكن تغييرها من لوحة الإدارة > الإعدادات.

## المميزات
- حفظ الطلب فورًا في Firebase قبل فتح واتساب.
- رقم طلب تلقائي.
- لوحة طلبات مع حالات: جديد / جاري التنفيذ / مكتمل.
- إشعار داخل لوحة الإدارة مع صوت عند وصول طلب جديد.
- رفع ملفات PDF / Word / صور عبر Firebase Storage.
- تتبع الطلب برقم الطلب.
- صفحة أسعار قابلة للتعديل.
- تقييمات العملاء.
- وضع ليلي/نهاري.
- PWA قابلة للتثبيت كتطبيق جوال.
- إدارة الخدمات والأسعار والحذف والإضافة.
- فتح واتساب برسالة منسقة جاهزة للإرسال.

## مهم لتفعيل رفع الملفات
من Firebase Console افتح Storage ثم Rules وضع مؤقتًا أثناء التجربة:

rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /{allPaths=**} {
      allow read, write: if true;
    }
  }
}

ولـ Firestore أثناء التجربة:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}

يفضل لاحقًا استبدال القواعد بقواعد آمنة عند النشر التجاري.


تحديث جديد:
- تم حذف رفع ملفات الطلب من واجهة العميل بالكامل.
- عند إضافة خدمة يمكنك كتابة رمز أو الضغط على اختيار صورة/أيقونة من الملفات أو الاستديو.
- تمت إضافة ثيمات وخطوط قابلة للتغيير من الإعدادات.
- لم تعد هذه النسخة تحتاج Firebase Storage.
