- تم نقل دخول لوحة المختص إلى Firebase Authentication (Email/Password).
- من Firebase Console > Authentication > Sign-in method فعّل Email/Password.
- أنشئ المستخدم الإداري من Authentication > Users.

- فتح واتساب برسالة منسقة جاهزة للإرسال.

## مهم لتفعيل رفع الملفات
من Firebase Console افتح Storage ثم Rules وضع مؤقتًا أثناء التجربة:

rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /{allPaths=**} {
      allow read, write: if true;
    }
  }
}

ولـ Firestore أثناء التجربة:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}

يفضل لاحقًا استبدال القواعد بقواعد آمنة عند النشر التجاري.
