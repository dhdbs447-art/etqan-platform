# منصة إتقان التعليمية - النسخة الاحترافية

## التشغيل
افتح ملف `index.html` مباشرة أو ارفعه على Netlify / Vercel / GitHub Pages / Firebase Hosting.

## دخول الإدارة
اسم المستخدم: admin  
كلمة المرور: admin

يمكن تغييرهما من: لوحة الإدارة > الإعدادات.

## المميزات
- تصميم عربي احترافي ومتجاوب.
- تخزين دائم عبر Firebase Firestore.
- إضافة وتعديل وحذف الخدمات.
- إدارة طلبات العملاء.
- تغيير رقم واتساب ورابط تلجرام من لوحة الإدارة.
- تطبيق PWA قابل للإضافة على شاشة الجوال.
- يعمل مع LocalStorage احتياطيًا إذا انقطع Firebase.

## تنبيه أمني
قواعد Firestore المفتوحة مناسبة للتجربة فقط. للإطلاق الحقيقي، استخدم Firebase Authentication وقواعد حماية مخصصة.
